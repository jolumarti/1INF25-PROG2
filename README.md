## Important note

- You must generate your own `lib.a` library so it works correctly on your device.
- Make sure your folder paths do not contain spaces, since a line like `set(CMAKE_CXX_FLAGS "${CMAKE_CXX_FLAGS} -L${CMAKE_CURRENT_SOURCE_DIR}/Libraries")` must work without issues.
